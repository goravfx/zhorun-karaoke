# Спой на страпонском

Караоке на песни группы «Жорун»: «Мандалупа», «Шмыздя Пыздя», «Вяльный конь», «Остановысь Мразня» и другие. Можно петь поверх клипа (или фотографий группы, если клипа у песни нет) или снимать себя на камеру: слова загораются в такт, а в конце получается вертикальный ролик для VK Клипов. Всё собирается прямо в браузере телефона.

В режиме камеры можно надеть маску Жоруна или его жены Мандалупы. Маски сделаны по их фото и держатся на лице в движении.

Сайт: https://goravfx.github.io/zhorun-karaoke/
