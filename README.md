# Спой на страпонском

Караоке группы «Жорун» на песню «Мандалупа». Можно петь поверх клипа или снимать себя на камеру: слова загораются в такт, а в конце получается вертикальный ролик для VK Клипов. Всё собирается прямо в браузере телефона.

В режиме камеры можно надеть маску кого-то из группы: Жоруна, барабанщика, аккордеониста, трубача или гитаристки. Маски сделаны по фото участников и держатся на лице в движении.

Сайт: https://goravfx.github.io/zhorun-karaoke/
